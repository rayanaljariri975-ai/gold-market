# GOLD MARKET

سوق عربي RTL لعرض إعلانات حسابات الألعاب. التقنية: Next.js 15 + Supabase (Auth, Postgres, Storage, Realtime).

## المتطلبات
- Node.js 20.9 أو أحدث
- حساب Supabase مجاني
- بريد إلكتروني يمكنه استقبال روابط تسجيل الدخول

## التشغيل المحلي
1. فك ضغط المشروع ثم افتح المجلد في VS Code.
2. شغّل `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. أنشئ مشروعاً مجانياً في https://supabase.com ثم انسخ Project URL و anon public key إلى `.env.local`.
5. افتح Supabase > SQL Editor وشغّل كامل `supabase/schema.sql`.
6. سجّل دخولك مرة واحدة عبر الموقع، ثم نفّذ في SQL Editor:
   ```sql
   insert into public.admin_users(user_id)
   select id from auth.users
   where lower(email)='rayanaljariri975@gmail.com'
   on conflict do nothing;
   ```
   البريد نفسه موجود في `ADMIN_EMAILS` لتفعيل صفحة إدارة مراجعة الإعلانات. أبقِ جدول admin_users هو مصدر صلاحية الإدارة في قاعدة البيانات.
7. من Storage أنشئ bucket باسم `listing-images` واجعله Public. سياسات الرفع والقراءة موجودة في ملف SQL.
8. من Authentication > URL Configuration أضف `http://localhost:3000/auth/callback` إلى Redirect URLs.
9. شغّل `npm run dev` وافتح http://localhost:3000.

## لوحة الإدارة
بعد تسجيل الدخول بالبريد `rayanaljariri975@gmail.com` افتح `/admin`. المصادقة برابط OTP إلى البريد، ولا يوجد رمز ثابت أو كلمة مرور داخل الكود. أضف حساب المدير إلى `admin_users` بعد أول تسجيل دخول كما في الخطوة 6.

## النشر المجاني
- ارفع المستودع إلى GitHub.
- اربطه بخدمة Vercel (خطة Hobby المجانية للمشاريع الشخصية) أو Cloudflare Pages مع إعدادات Next.js المناسبة.
- أضف متغيرات `.env.example` في إعدادات المشروع على منصة النشر، مع `NEXT_PUBLIC_SITE_URL` كرابط النشر.
- في Supabase Authentication أضف رابط الموقع المنشور إلى Redirect URLs.
- لاحقاً يمكن ربط دومين مخصص من إعدادات منصة النشر دون تغيير بنية التطبيق.

## ما هو جاهز في هذه النسخة
- واجهة عربية سوداء وذهبية ومتجاوبة.
- تسجيل دخول OTP بالبريد.
- إنشاء إعلان بحالة pending، ولا يظهر للعامة إلا بعد الموافقة.
- صفحة مراجعة إعلانات المدير.
- ملفات SQL للجداول والصلاحيات، المحادثات الفورية، التقارير والمعاملات.
- رفع صور الإعلان إلى Supabase Storage.

## نقاط يجب إكمالها قبل فتح السوق للجمهور
هذه نسخة تأسيسية عاملة وليست منصة تجارة مكتملة مدققة أمنياً. يلزم قبل الإطلاق:
- إضافة واجهات إدارة المستخدمين والبلاغات والمشرفين بصلاحية `chat_moderator`، واختبارات صلاحيات شاملة.
- إضافة تقييمات لا تُتاح إلا بعد معاملة مؤكدة، وإكمال دردشة عامة مع أدوات بلاغ وحظر.
- إكمال حقول إيفو الديناميكية (اسم/مستوى لكل سلاح) والتحقق من مدخلات كل لعبة على الخادم.
- ربط مزود دفع مرخص في بلد التشغيل مع Webhooks موثقة؛ لا تستقبل أموالاً أو تعرض دفعة كمدفوعة قبل تحقق المزود. لا توجد معالجة دفع في هذه النسخة.
- إضافة تحويل عملات من مصدر أسعار موثوق مع تخزين السعر الأصلي ووقت التحويل.
- ضبط SMTP مخصص في Supabase حتى تصل رسائل OTP بصورة موثوقة.
- إعداد سياسة خصوصية وشروط استخدام وآلية نزاعات، والتحقق من توافق بيع الحسابات مع شروط كل منصة. لا تطلب من المستخدمين كلمات مرور الحسابات أو رموز الاسترداد.

## الأمان
- لا تضع `SUPABASE_SERVICE_ROLE_KEY` في متغير يبدأ بـ `NEXT_PUBLIC_` ولا في كود المتصفح.
- لا ترفع `.env.local` إلى GitHub.
- تفعيل OTP لا يعني وجود MFA قوي للمدير؛ أضف MFA/TOTP من إعدادات Supabase قبل الإطلاق.
- راجع RLS والسياسات واختبرها بحسابات منفصلة قبل نشر بيانات حقيقية.
